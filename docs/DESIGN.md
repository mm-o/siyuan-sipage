# 设计语言

目标：卡片内容清楚，操作轻巧，层级一致。采用 [Apple Design Skill](https://github.com/dickwu/apple-design-skill/blob/main/SKILL.md) 的 HIG 原则；CSS 玻璃是 Electron 内的材质近似。

## 单一来源

共享颜色、材质、间距、字号与动效在 `src/styles/index.css`；组件 scoped 样式负责自身排版。外观设置通过 `store.ts` 同步到 CSS 变量，桌面和设置预览读取同一批参数。设置的标题、说明、分组、滑轨和开关骨架只维护一份。

| 用途 | 当前令牌/约定 |
| --- | --- |
| 正文/标题/辅助字 | 13/15/11px，正文使用 Regular 或更重字重 |
| 圆形操作命中区 | `--desk-hit`，28px |
| 卡片圆角 | `--desk-r-card`，由外观设置同步 |
| 弹层外缘/内接圆角 | 18/6px |
| 弹层外圈/栏内留白/栏间距 | 12/20/8px |
| 常规/清透模糊 | `--desk-blur-regular` / `--desk-blur-clear` |
| 容器断点 | 120/200/260/460/720px |

以上具体值是项目实现，不视为 Apple 对所有界面的固定数值要求。

## 材质与内容

- Liquid Glass 用于浮动功能层，整理工具栏与操作控件保持少量、单色；完成按钮是该视图唯一强调动作。
- 卡片面由 `registry.surface` 决定。`solid` 使用不透明面，文字密集卡片保持清楚；默认半透明外框沿用现有卡片材质，不逐卡重复实现。
- 纯色卡片忽略玻璃模糊和不透明度设置，悬浮控件使用纯色面专用配色。
- 浅深色使用相同语义变量的不同值；图上文字保持白色并配遮罩。
- 跟随思源 = 什么都不画：页签容器、页签根、桌面层全部让开，露出来的就是思源自己的背景（主题色或主题背景图），四角与思源同一份像素；照片底上的白字与深色药丸换回主题墨色。
- 桌面直接铺满页签，不自己内缩、不自己裁圆角：照片就是整块底，圆角交给思源容器那一层。
- 图片内容卡的卡面与详情共用 `dailySeries()`，同一条内容使用同一张图；背景来自思源头图，翻页与手动换背景保持同步。

依据：`materials.md › Liquid Glass` 的 “Use Liquid Glass effects sparingly” 与功能/内容分层；`color.md › Liquid Glass color` 的单色控件、克制强调色。

## 公共液态玻璃控件

所有动作使用 `ui/controls.ts` 的 `GlassButton`：默认图标形态，`text` 显示文字；`variant` 只有 default/primary/danger；`tone="photo"` 用于壁纸、照片与天气天空。按钮保留原生 type、disabled、事件与 aria 状态，表单提交不另造事件链。

材质沿用已确认的 `docs/prototypes/liquid-glass.html`：清透背景、边缘折射、顶部内侧高光、指针高光与短按反馈。全页只生成 icon/pill 两张法线图和一个滤镜根，按钮共用，无逐按钮 canvas 或 ResizeObserver。

`--dg-*` 令牌集中在共享样式：浅色深字、深色浅字，响应思源 `body--dark` 与根节点主题属性；照片环境保持白字。普通选中使用主题色，危险操作使用危险色。减少透明度/增加对比度时不使用折射和模糊，减少动效时关闭位移和过渡。

Segmented、Chips、开关、输入框、滑轨及勾选框使用同一组边缘与状态令牌；选择列表只强化选中项，内容布局不重复绘制模糊。原生菜单仍由思源提供。`shot-glass.mjs` 验证主题切换、滤镜单例、按钮结构、表单提交、焦点与无障碍降级。

## 整理桌面

画布仍使用原壁纸，独立轻遮罩压低干扰。每格用 CSS 点阵标记，每四格一条弱参考线；网格与卡片共用 `grid.unit`，随画布滚动，不逐格创建元素。

顶部玻璃工具栏显示数量、实时提示、一键整理和完成，预留操作区避免遮盖内容。浅色 84% 白、深色 88% 深灰；完成按钮复用公共主要动作，材质层与白字对比度检查为浅深色均 5.29:1。

悬停或键盘聚焦才展示四边缩放手柄、移动标记和名称/尺寸标签；标签避开手柄。拖动时保留起始轮廓、突出当前对象，其他控件退场；尺寸到边界后仍可向反方向调整。操作对象直接跟手，无循环动画与指针轮询。

方向键移动，Shift + 方向键缩放；缩放按钮也支持方向键。Esc 和完成均退出整理；窄窗口保留主要操作。减少透明度或高对比度时使用实色功能面，减少动效时关闭过渡。

依据：`layout.md › Visual hierarchy` 的内容与操作分层；`motion.md › Providing feedback` 的跟随手势与简短反馈；`accessibility.md › Mobility` 的命中区与键盘替代操作。

## 表面与表单控件

弹层、桌面卡片和内容面共用一套表面令牌，不再各自写底色与描边：

- `.desk-surface` 给框架卡片；`--dg-surface-*` 变量按日夜与外观设置派生，信息卡用更厚的玻璃变体。
- `.desk-pane` 给弹层各栏与设置分区，顶栏与内容栏同一材质、不描边，缝隙露出遮罩。
- `.desk-content-surface` 给列表行、内容块这类浅层元素，不叠加背景模糊，只保留边缘高光、选中边与悬停反馈。
- 可选择行（导航、卡片库、来源、分类、地点、文档、备忘）共用一条悬停/选中/焦点规则，业务样式只负责布局；滚动条隐藏与滚动区外观也只有一处定义。
- 照片、天气天空、图表数据色、进度环仍由卡片自绘；这些是内容语义色，不参与表面统一。

字段只使用 `GlassField`（原生 input / textarea），下拉只使用 `GlassSelect`，开关只使用 `GlassSwitch`，滑轨只使用 `Slider`。四者共用 `--dg-field-*`、`--dg-track` 与焦点环令牌 `--desk-ring`（各处只调 `outline-offset`）；表单保留原生 type、submit、disabled、`v-model.number`、输入法组合和事件透传。原生 `select` 的弹层无法自绘，`GlassSelect` 用 listbox 顶替它：触发器沿用字段外观与自绘箭头，弹层是同一套玻璃面（`.desk-pop`），方向键 / Home / End / Esc / 点外关闭全部自理，并把它自己声明为当前焦点层。数量与「已添加」状态统一为 `.desk-badge`，有内容时用强调色。同一动作或卡片可以重复添加，列表行用徽章显示已添加数量；图标型危险操作平时中性、悬停才亮危险色，避免整列发红。`shot-surfaces.mjs` 与 `shot-controls.mjs` 验证这些行为以及弹层材质的日夜切换。

## 日程与备忘

日程与备忘是同一张表上的两种身份，不是两套数据：`core/agenda.ts` 里一条 `PlanItem` 有 `date` 就是日程（占日历那一天），没有 `date` 就是备忘（待在收件箱）。勾掉、备注、时间、换日期都落在同一个对象上，所以「安排到某天」只是给同一个对象填了个日期，不存在复制或同步。

| 视图 | 读什么 | 写什么 |
| --- | --- | --- |
| 日程备忘卡 | 今天 → 逾期 → 备忘 三段 | 一个输入框，永远加到今天；圆点勾掉 |
| 日程备忘详情 | 今天 / 逾期 / 即将 / 收件箱 / 已完成 五个分组 | 标题、日期、时间、备注与「今天 / 明天 / 收件箱」快捷去处，改即写 |
| 日历详情 | 左黄历（节气宜忌）/ 中月历（格子圆点）/ 右日程（当天清单） | 内联添加、勾掉、可选写入今天的日记 |

- 一份真源：卡片、详情、日历读同一份 reactive 状态与按日索引，切换视图不重算、不落第二份。
- 卡片只回答「今天还剩什么」，未来的日子留给日历，同一件事不在两处各说一遍。
- 行数不猜：卡片按列表实测高度切行（28px 命中区 + 间距），装不下就少显示几条，绝不把一行切成两半。
- 写完即结束：右栏改字段直接写模型，没有保存按钮；卡片只留一个入口（加到今天）。
- 日记是出口不是真源：思源没有独立日程对象，需要进文档时用「写入今天的日记」抄一份待办块（默认关、只对今天生效），失败只提示、不丢本地条目。
- 日期一律 `YYYY-MM-DD` 字符串比较；跨零点由 `agenda.ts` 的分钟 tick 重算「今天 / 逾期」，挂着过夜的卡片不会停在昨天。
- 一处排版：日历右栏与备忘详情的条目共用 `.mm-line`（圆点 + 时间 + 标题 + 完成划线），只在这里定义；两栏宽度共用 `--desk-aside-w` / `--desk-detail-w`。
- 月格只有一份：`ui/MiniCalendar`（em 计量，宿主给字号即换档）同时供桌面日历卡与日记详情的小日历使用，月份切换 / 周首 / 今天 / 日程点都在组件内。`n- 三栏降级：容器 ≤720 收起黄历、工具栏换行不截断；≤460 改成月历在上、日程在下的上下叠放（容器不能查询自己，布局壳 `.cal-body` 单独一层）。
- 圆点与行反馈复用共享的 `.mm-dot` / `.mm-row`，日程与备忘在卡片、详情、日历里看起来是同一件东西。

## 弹层与全屏

所有设置与详情使用 `Sheet.vue`：透明布局壳、统一标题栏、一组内容栏；打开时焦点进入弹窗，Tab 在窗内循环，Esc 关闭并把焦点还给触发元素。首次打开居中，拖顶栏平移、拖四角缩放（下限 380×260，且至少留 120px 宽与 48px 顶栏在视口内），双击顶栏回到居中；这些只在第一次交互时把居中矩形冻结成一个绝对盒，开关一次即复位，打开与关闭的 FLIP 动画不受影响。

详情是**每张卡一个独立弹窗**（`DeskShell` 里 `sheets` 列表，一条一个 `Sheet` 实例）：同一张卡再点不重复开；未钉住的弹窗会顶替上一个未钉住的，钉住的一个都不动，所以可以同时钉住多张卡的弹窗。多弹窗共存时 Esc 与 Tab 只作用于最上面那一层（DOM 末尾的遮罩）。

```text
Sheet
├─ .desk-sheet-head.desk-pane.is-top    图标、标题、钉住、调用方动作、关闭（拖动把手）
├─ .desk-sheet-body
│  └─ .desk-pane                      各卡片内容或设置分区
└─ .desk-sheet-grip.is-nw/ne/sw/se      四角缩发热区
```

面材质只在 pane 上出现一次，栏间缝隙透出遮罩。位置类只用 `is-top/bottom/left/mid/right/solo` 管圆角；卡内裁切，弹层滚动层放在圆角裁切层内部。

卡片详情默认 760×560 的视口受限尺寸，特例通过 `registry.detailSize` 声明；设置为 `min(1040px,94vw) × min(660px,86vh)`。分区为壁纸、组件设置、卡片库、关于，预览与重置统一在外壳。

FLIP 开启 280ms、关闭 220ms，减少动效时直接切换。钉住去掉背景遮罩与模糊，同时让遮罩不再拦截指针：点外部既不关闭，也能直接操作背后的桌面；弹窗自身恢复指针，互不影响。钉住状态由调用方持有（`v-model:pinned`），所以能同时钉住多张卡的弹窗，且点别的卡不会把钉住的那个换成别的卡片。取消钉住后遮罩恢复拦截，点外部即关闭。

全屏由桌面壳提供，卡片内容直接铺满屏幕，不包第二套卡框。详情转全屏继承当前实例尺寸；右下退出按钮或 Esc 关闭。全屏、更多按钮停止冒泡，避免同时打开详情。

## 图标、控件与菜单

功能图标使用 `lucide-vue-next`，线条宽约 1.7，明确 `fill:none` 以抵消思源全局样式；快捷方式卡槽内的图标同样只描边，由符号或 lucide 自带设置决定，公共样式不再写 `fill: currentColor`。品牌图形例外，保留当前四方块，在 `ui/controls.ts` 定义、由宿主或验证页注册；顶栏、页签与桌面直接引用 `iconDeskCards`。

- 普通圆形按钮用 `GlassButton`，标签写入 `aria-label`，思源提示通过 `ariaLabel` 显示。
- ≤4 个等宽单选使用 `Segmented`，更多选项使用 `Chips`；照片底标签使用 `on-photo`。
- 菜单交给思源原生 `Menu`。卡片菜单只有打开、刷新、移除；尺寸在整理模式调整。
- 卡片本身负责内容；悬浮菜单、全屏、材质和弹层不在各卡片重复实现。

## 数据型卡片

- 日历与倒数日日期算法使用 `tyme4ts`，实现留在对应卡片或已有默认状态初始化位置。
- 天气数据集中在 `cards/weather/weather.ts`，国内与国际后端各有适配，卡片和详情共用数据；地点管理由 `PlacesDrawer.vue` 提供。
- 写作热力图用单色强度表达写作量，数字和图例补充颜色信息。SQL 显式限制行数，避免思源默认返回上限截断结果。
- 字数与写作量只数正文块（`BODY_TYPES`）：文档块的 `length` 是标题，混进来会把统计变成「标题总长度」。
- 文档统计图谱的拖动、缩放与点击由图谱组件管理，卸载释放全局事件；不让查询回调在已卸载后继续初始化。
- 日记卡按 `attributes` 的 `custom-dailynote-YYYYMMDD` 找当天文档：卡片给「字 / 待办 / 前几行」，详情**就地编辑**并保留思源文档的全部功能（标题、面包屑、块图标、工具栏；`mountProtyle({ editable, full })`），停笔刷新字数。日记详情左栏顺序固定为「日号 → 日期 → 统计行 → 小日历 → 待办」，**统计行永远占位**（没有日记显示 `0 块 · 0 字`），日期切换不让版面上下跳；点待办滚到正文对应行，`/` 提示菜单挂到 `body` 以摆脱弹层的包含块。取数在 `core/dailyNote`，日历右栏可直接打开这天的日记。
